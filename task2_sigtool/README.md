# Задание 2. Генератор байтовых сигнатур (sigtool)

**Кратко:** по группам файлов G1 и G2 выдаёт набор байтовых массивов: каждый файл G1 содержит хотя бы один из них, ни один файл G2 не содержит ни одного. Кандидаты — хеши k-грамм с winnowing, выбор — жадное покрытие множества, расширение до 64 байт, финальная побайтовая проверка. APK/ZIP/JAR раскрываются до записей (`--unpack`). Вывод: text, JSON, YARA.

| Путь | Содержимое |
|---|---|
| `sigtool.py` | Инструмент (Python 3 + NumPy) |
| `test_sigtool.py` | 8 модульных тестов |

## Как проверить
```
pip install numpy
python3 -m unittest -v test_sigtool          # 8 passed (YARA-тест пропускается, если нет yara)
python3 sigtool.py --g1 G1/ --g2 G2/                     # текстовый вывод
python3 sigtool.py --g1 G1/ --g2 G2/ --unpack -f yara -o rule.yar
```

Основные ключи: `-k` минимальная длина (12), `-w` окно winnowing (32; 1 — полный перебор), `--max-len` (64), `-r` сколько сигнатур на файл, `--require-all` только общие для всех G1, `-f text|json|yara`.

Коды возврата: 0 — все файлы G1 покрыты, 1 — есть непокрытые (например, файл G1 целиком входит в G2), 2 — ошибка финальной проверки.

## Оговорки
- Жадное покрытие не гарантирует минимального числа сигнатур (задача NP-трудна).
- При `-w` > 1 общие фрагменты короче w + k − 1 = 43 байт могут быть пропущены.
- С `--unpack` сигнатуры берутся из распакованных записей — сканировать нужно извлечённые файлы, а не сжатый APK.
