# Задание 1. Подборка вредоносных APK с вердиктами вендоров

**Кратко:** 2000 SHA-256 вредоносных APK (58 семейств) и 16 772 вердикта вендоров: 12 762 из MalwareBazaar (ReversingLabs, Triage, CERT-PL MWDB, FileScan-IO, Spamhaus, InQuest, YOROI, Kaspersky OpenTIP) и 4010 от AV-движков VirusTotal (137 образцов). Бонус: 196 вредоносных файлов внутри 112 APK. Образцы не скачивались, всё собрано по API.

| Путь | Содержимое |
|---|---|
| `out/apk_verdicts.csv` | 2000 строк: MD5, SHA-1, SHA-256, семейство, вердикты вендоров MalwareBazaar, 24 ключевых AV-движка VirusTotal, вредоносные вложенные файлы |
| `out/apk_verdicts_long.csv` | 16 772 строки «SHA-256 — источник — вендор — вердикт», все вендоры |
| `out/apk_inner_files.csv` | 196 вредоносных файлов внутри APK: имя, SHA-256, тип, число детектов, примеры вердиктов |
| `out/apk_verdicts.json` | Все собранные данные, включая Androguard-метаданные (пакет, опасные разрешения) |
| `out/REPORT.md` | Автоматическая сводка: семейства, покрытие, примеры |
| `collect.py` | Скрипт сбора (Python 3, только стандартная библиотека) |
| `cache/` | Сырые ответы API (`mb/`, `vt/`), из которых собраны выгрузки |

## Как проверить
```
python3 collect.py --report-only    # пересобрать out/ из cache/ без обращения к API
```
Результат побайтово совпадает с приложенным `out/`.

Полный сбор заново нужны ключи (в материалы не включены):
```
export MB_AUTH_KEY=…  VT_API_KEY=…
python3 collect.py --mb-limit 2000 --vt-files 300 --vt-bundled 150
```

## Оговорки
- Детекты VirusTotal есть для 137 образцов: публичный ключ ограничен 4 запросами в минуту и 500 в сутки. Для остальных — вердикты вендоров из MalwareBazaar (есть у 1996 из 2000).
- Пояснения к вложенным `resources.arsc`, `index.html`, `config.json` в отчёте сделаны по именам и типам, вручную не проверялись.
